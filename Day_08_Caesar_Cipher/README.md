# Caesar Cipher (Python)

## Introduction

This project is a simple Python implementation of the **Caesar Cipher** encryption technique. The Caesar Cipher is one of the oldest methods used to protect messages by shifting letters in the alphabet.

## How it Works

In this program, each letter in the message is shifted by a certain number of positions in the alphabet.

For example:

* Message: `hello`
* Shift: `2`
* Encrypted message: `jgnnq`

The program can also **decode** the encrypted message by shifting the letters backward.

## Features

* Encrypt a message (encode)
* Decrypt a message (decode)
* Handles spaces and symbols without changing them
* Allows the user to run the program multiple times

## How to Run

1. Run the Python file.
2. Choose `encode` to encrypt or `decode` to decrypt.
3. Enter your message.
4. Enter the shift number.

The program will display the encrypted or decrypted message.
