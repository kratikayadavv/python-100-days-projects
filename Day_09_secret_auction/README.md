**Secret Auction Program**
This is a simple Python program that simulates a secret auction system.
Multiple users can enter their names and bids, and at the end, the program determines who placed the highest bid.

The bids are kept hidden from other participants, just like a real secret auction.

⚙️ **How It Works**

The program asks each user for:

Their name

Their bid amount

Each bid is stored in a dictionary

The program keeps asking if there are more bidders

When all bids are entered, it finds the highest bidder

Finally, it displays the winner and their bid

**🧠 Concepts Used**

Dictionary (to store names and bids)

Loops (while)

Conditional statements (if-else)

Functions

Basic input/output
