# Coffee Machine ☕

A command-line Coffee Machine simulator built using Python.

The program allows users to order drinks, checks ingredient availability, processes coin payments, calculates change, updates resources, and tracks profit.

## Features

* Order Espresso, Latte, or Cappuccino
* Resource availability checking
* Coin-based payment system
* Change calculation
* Profit tracking
* Resource report generation
* Machine shutdown option

## Concepts Used

* Functions
* Dictionaries and Nested Dictionaries
* Loops
* Conditional Statements
* Global Variables
* State Management
* Resource Tracking

## How It Works

1. User selects a drink.
2. The machine checks if enough ingredients are available.
3. The user inserts coins.
4. The machine verifies payment.
5. If payment is successful:

   * Ingredients are deducted.
   * Profit is updated.
   * The drink is served.
6. The process repeats until the machine is turned off.
