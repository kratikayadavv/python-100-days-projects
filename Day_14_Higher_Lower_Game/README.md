# Higher Lower Game

A command-line Python game where players compare two accounts and guess which one has more followers.

## Features

* Random account comparison
* Score tracking
* Continuous gameplay until a wrong guess
* Uses real follower count data
* Prevents duplicate comparisons

## Concepts Used

* Functions
* Dictionaries
* Lists
* Loops
* Conditional Statements
* Random Module
* Game State Management

## What I Learned

* Working with dictionaries and nested data
* Using functions to organize code
* Returning Boolean values (`True` / `False`)
* Managing game state and score
* Building a complete command-line game

## Technologies Used

* Python 3
