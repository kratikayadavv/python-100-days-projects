# Number Guessing Game (Python)

A simple command-line number guessing game built in Python. The player tries to guess a randomly generated number between 1 and 100 within limited attempts.

# Features
Two difficulty levels:
Easy (10 attempts)
Hard (5 attempts)
Feedback after each guess:
"Too high" or "Too low"
Tracks remaining attempts
Ends when:
Player guesses correctly ✅
Player runs out of attempts ❌

# Technologies Used
Python
Random module

# How It Works
The program generates a random number between 1 and 100.
The player selects a difficulty level.
The player keeps guessing until:
They find the correct number, or
They run out of attempts.
