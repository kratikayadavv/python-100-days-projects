# Quiz Project 🧠

A simple **True/False Quiz Game built with Python**.

## Features

* Loads questions from a separate data file.
* Uses a `Question` class to store question details.
* Uses a `QuizBrain` class to manage the quiz logic.
* Keeps track of the user's score.
* Displays the final score after completing the quiz.

## Project Structure

```text
quiz-project/
│
├── main.py
├── question_model.py
├── quiz_brain.py
└── data.py
```

## How to Run

1. Make sure Python is installed.
2. Clone or download the project.
3. Run:

```bash
python main.py
```

Answer each question when prompted and see your final score at the end!
