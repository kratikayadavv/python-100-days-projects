# Blackjack Game

This project is a simple command-line Blackjack game built using Python. It helped me understand how real game logic works step by step.

# What I Learned
# Functions
I learned how to break code into small reusable parts like:
deal_card() → gives a random card
calculate_score() → calculates total score
compare() → decides winner
play_game() → controls the full game flow
# Game Logic
How Blackjack works (21, Ace = 11 or 1)
Detecting Blackjack (2 cards = 21)
Handling score > 21 (bust condition)
Computer logic (keeps drawing until score ≥ 17)
# Lists
Used lists to store user and computer cards
Learned how to add/remove elements dynamically
Conditions (if-else)
Compared scores to decide win/lose/draw
Managed multiple game scenarios
# Loops
Used while loop to keep the game running
Controlled when the game should stop
# Random Module
Used random.choice() to simulate card dealing
# Key Concept

Instead of writing long messy code, I learned how to:
👉 Divide the problem into smaller functions
👉 Combine them to build a complete working game
